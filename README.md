# CyberVault

CyberVault es una plataforma web para gestionar **comandos de hacking ético**, donde los usuarios pueden **agregar, editar, eliminar y buscar comandos** de forma sencilla y rápida.  
Está pensada para profesionales y estudiantes que quieran organizar, guardar y aprender sobre hacking etico.

---

## Tecnologías usadas

- **HTML**: estructura de la interfaz  
- **JavaScript (JS)**: lógica de la aplicación, eventos y manipulación del DOM  
- **Tailwind CSS**: estilos modernos y responsivos    

---

## Funcionalidades principales

1. **Agregar comandos de usuario**  
   - Permite escribir un comando y su descripción, y guardarlo en la lista.

2. **Editar comandos existentes**  
   - Los comandos del usuario se pueden modificar sin perder la información.

3. **Eliminar comandos**  
   - Permite borrar comandos del usuario de la lista.

4. **Buscar comandos**  
   - Filtrado en tiempo real por nombre o descripción, tanto para comandos predefinidos como de usuario.

5. **Comandos predefinidos**  
   - Incluye ejemplos útiles de comandos de hacking ya preparados.

6. **Copiar comandos al portapapeles**  
   - Botón rápido para copiar cualquier comando sin necesidad de seleccionarlo.

---

## Ejemplos de uso

### Agregar un comando del usuario
en cada seccion hay un formulario para agregar un comando 
1. Escribe el comando en el campo **“Comando”**, por ejemplo:

nmap -sV 192.168.1.1

2. Escribe una descripción en el campo **“Descripción”**, por ejemplo:

Escaneo de servicios con Nmap



### Buscar un comando

Cada sección tiene una barra de búsqueda.
Escribe una palabra clave en la barra de búsqueda.
Por ejemplo, escribir nmap filtrará todos los comandos que contengan “nmap” en su descripción o texto.


### Editar un comando

Haz clic en el botón ✎ junto al comando que quieres modificar.

Eliminar un comando

Haz clic en el botón ✖ junto al comando que quieres borrar.

### Copiar un comando

Haz clic en el botón ⧉ para copiar el comando al portapapeles.
