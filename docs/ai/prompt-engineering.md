
# 1. Rol: desarrollador senior

**Prompt**

Actúa como un desarrollador senior de JavaScript. Revisa el siguiente código y sugiere mejoras de rendimiento, legibilidad y buenas prácticas.

**Uso**

Revisión de código.

**Por qué funciona**

Definir un rol hace que la IA responda con criterios más profesionales y enfocados en buenas prácticas.

---

# 2. Rol: experto en seguridad web

**Prompt**

Actúa como un experto en seguridad web. Analiza este código y detecta posibles vulnerabilidades.

**Uso**

Auditoría básica de seguridad.

**Por qué funciona**

La IA enfoca su análisis en seguridad en lugar de revisar el código de forma general.

---

# 3. Generación de código con restricciones

**Prompt**

Genera una función en JavaScript que valide un email.

Restricciones:

* Debe usar una expresión regular
* Debe devolver true o false
* No debe usar librerías externas

**Uso**

Generación de funciones concretas.

**Por qué funciona**

Las restricciones reducen ambigüedad y generan respuestas más precisas.

---

# 4. Refactorización de código

**Prompt**

Refactoriza esta función para que sea más legible y modular.
No cambies el comportamiento del código.

**Uso**

Mejorar calidad del código existente.

**Por qué funciona**

La restricción evita que la IA cambie la lógica original.

---

# 5. Documentación automática

**Prompt**

Genera documentación en formato Markdown para este archivo JavaScript.

Incluye:

* descripción
* funciones
* parámetros
* ejemplos de uso

**Uso**

Crear documentación rápida del proyecto.

**Por qué funciona**

Define estructura clara de salida.

---

# 6. Few-shot prompting (ejemplos)

**Prompt**

Convierte funciones JavaScript a comentarios de documentación.

Ejemplo:

Input:
function suma(a,b){return a+b}

Output:
Suma dos números y devuelve el resultado.

Ahora haz lo mismo con la siguiente función:
[FUNCION]

**Uso**

Explicar funciones automáticamente.

**Por qué funciona**

Los ejemplos ayudan a la IA a entender exactamente el formato esperado.

---

# 7. Explicación paso a paso

**Prompt**

Explica paso a paso cómo funciona este código JavaScript.

**Uso**

Comprender código complejo.

**Por qué funciona**

Obliga a la IA a razonar en etapas en lugar de dar una explicación superficial.

---

# 8. Análisis de estructura del proyecto

**Prompt**

Analiza la estructura del proyecto y explica el propósito de cada carpeta y archivo principal.

**Uso**

Entender proyectos grandes rápidamente.

**Por qué funciona**

Da contexto estructural en lugar de solo analizar archivos individuales.

---

# 9. Generación de tests

**Prompt**

Genera tests unitarios para esta función usando Jest.

Restricciones:

* mínimo 3 tests
* incluir caso válido
* incluir caso inválido

**Uso**

Crear pruebas automáticas.

**Por qué funciona**

Las restricciones garantizan cobertura mínima.

---

# 10. Mejora de rendimiento

**Prompt**

Optimiza este código JavaScript para mejorar rendimiento.

Restricciones:

* no cambiar la funcionalidad
* explicar los cambios realizados

**Uso**

Optimización de código.

**Por qué funciona**

La explicación permite entender las mejoras aplicadas.

---

# Conclusión

El prompt engineering permite mejorar la calidad de las respuestas de la IA.
Definir roles, usar ejemplos, pedir razonamiento paso a paso y establecer restricciones ayuda a obtener resultados más útiles para el desarrollo de software.
